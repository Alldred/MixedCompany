MixedCompany

A display typeface. Every letter is its own drawing, including the accented ones. Repeated letters cycle through extra designs.

MixedCompany — proportional
MixedCompany Mono — fixed width

Install the TTF files, or open MixedCompany-Try-It.html to try both.

Repeated letters (contextual alternates, on by default):
see  little  look  less  Mississippi
